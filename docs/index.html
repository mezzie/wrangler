The Open-Source Window Manager for macOS

Visual grid overlays, ultrawide drop zones, and automated tree tiling.
100% native Swift. Zero SIP disabling. Free forever.

Download Wrangler.dmg macOS 13 (Ventura) or later • Apple Silicon & Intel • 1.5MB
$ brew install mezzie/tap/wrangler

Built for Speed & Precision

Everything you need to organize your desktop without the bloat.

🎯

Interactive Grid Overlay

Press ⌥ Space to summon a floating glass grid at your mouse cursor. Click and drag across cells to resize any window with a live blueprint preview.

⌥ Space
🧲

Snap Zones (Drag-to-Snap)

Drag any window by its title bar to screen edges to snap into 50/50 dual splits, 3-column layouts, or 25|50|25 center-focus templates tailored for ultrawide displays.

Mouse Drag
🪟

AeroSpace-Style Auto-Tile

Press ⌃ ⌥ T to automatically reorganize all open windows on your display into a balanced Binary Space Partitioning (BSP) tree in 0.1s. Zero overlap.

⌃ ⌥ T
🗂️

Workspaces (App Profiles)

Save your entire multi-window desktop arrangement into named profiles (Coding, Research, Meeting) and restore all apps to their exact coordinates in 1 click.

App-to-Slot
🔄

Spatial Navigation & Swap

Use Vim-style H/J/K/L keys to jump focus across windows directionally, or press ⌃ ⌥ S to reciprocally swap the two frontmost windows.

⌃ ⌥ H / J / K / L
🛡️

Apple Notarized & Native

Pre-approved by Apple Gatekeeper servers with hardened runtime. Runs in ~15MB RAM and uses standard Accessibility APIs with zero SIP disabling required.

Gatekeeper Safe

Keyboard Shortcuts

Fast, ergonomic shortcuts for every action. Fully customizable in Preferences.

Shortcut Action Description
⌥ Space Show Grid HUD Opens interactive grid overlay at mouse cursor
⌃ ⌥ ↵ or ⌃ ⌥ M Maximize Window Expands focused window to full visible screen
⌃ ⌥ T Auto-Tile Display Organizes all open windows into a non-overlapping BSP tree
⌃ ⌥ S Swap Windows Swaps positions of the two frontmost windows
⌃ ⌥ H / ⌃ ⌥ L Focus Left / Right Jumps keyboard focus to adjacent window horizontally
⌃ ⌥ K / ⌃ ⌥ J Focus Up / Down Jumps keyboard focus to adjacent window vertically
⌃ ⌥ ` Cycle App Windows Cycles through open windows of the active application
⌃ ⌥ → / ⌃ ⌥ ← Next / Prev Display Shifts focused window to another connected monitor
⌥ ⌘ Z Undo Snap Restores window coordinates before the last snap
⌘ , Preferences Opens sidebar settings for grid sizes, margins, and keys
